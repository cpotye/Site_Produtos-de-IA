# Landing Page — Agentes de IA

Landing page premium para empresa especializada em automação de processos e desenvolvimento de Agentes de Inteligência Artificial.

## Stack

Arquivo único HTML/CSS/JS. Sem build, sem dependências além de fontes do Google.

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir com qualquer HTTP server:

```bash
python3 -m http.server 8000
# depois abra http://localhost:8000
```

## Estrutura

- `index.html` — página completa (nav, hero, problema, soluções, integrações, benefícios, como funciona, segurança, agentes, depoimentos, CTA, rodapé)
- `.gitignore`
- `README.md`
